详细描述

template<typename TChar>
struct IOv2::istream_operators< TChar >

为输入流提供各类提取操作的混入（mix-in）基类。

本模板集中承载 get、peek、read、ignore、putback 等成员，供具体输入流类型 派生使用；这些成员通过 deducing-this（this TSelf& self）以派生类的具体类型执行操作。 每个操作先取本流的 io_mutex()，再在锁内构造输入哨兵以完成前置准备，并将异常统一交由流的 handle_exception 处理，从而按异常掩码更新流状态。

模板参数
TChar字符类型。

将字符提取到输出序列，直到遇到换行符、缓冲区满或到达 EOF。

等价于以当前 locale 下 '\n' 的宽化结果作为分隔符调用三参数版本 get<DelimPolicy, CStrPolicy>(s, n, delim)。

模板参数
DelimPolicy分隔符处理策略：cons_sep 或 keep_sep。
CStrPolicyC 字符串处理策略：app_zt 或 no_zt。
TOut输出目标类型：可为指针或输出迭代器。
参数
s输出目标（指针或输出迭代器）。
n缓冲区容量，必须为正；当 CStrPolicy 为 app_zt 时，最多写入 n-1 个字符。
返回
指向最后一个写入位置之后的输出迭代器/指针。app_zt 下空字符结尾 也是一个写入位置，因此返回值与 s 之差比提取到的字符数多一。
异常
stream_error若缺少 ctype facet（用于宽化 '\n'）；其余异常与三参数版本一致。

将字符提取到输出序列，直到遇到分隔符、缓冲区满或到达 EOF。

这是 get/getline 系列的策略化底层实现，行为由两个策略标签控制：

  • DelimPolicy：cons_sep 表示消费分隔符（getline 语义，分隔符被读走但不写入 输出）；keep_sep 表示保留分隔符（get 语义，分隔符留在流中）。
  • CStrPolicy：app_zt 表示在末尾追加空字符结尾（此时最多写入 n-1 个字符）； no_zt 表示不追加结尾。
    模板参数
    DelimPolicy分隔符处理策略：cons_sep 或 keep_sep。
    CStrPolicyC 字符串处理策略：app_zt 或 no_zt。
    TOut输出目标类型：可为指针或输出迭代器。
    TSelf派生的具体流类型（由 deducing-this 推导）。
    参数
    s输出目标（指针或输出迭代器）。
    n缓冲区容量，必须为正；当 CStrPolicy 为 app_zt 时，最多写入 n-1 个字符。
    delim分隔符。
    返回
    指向最后一个写入位置之后的输出迭代器/指针。app_zt 下空字符结尾 也是一个写入位置，因此返回值与 s 之差比提取到的字符数多一。
    异常
    stream_error若 s 为空指针、n 为负或为 0、未提取到任何字符，或 （cons_sep 下）在缓冲区容量内未找到分隔符。
    注解
    到达 EOF 时置位 eofbit——指本次提取还需要一个字符而没有；缓冲区填满后循环末尾 的那次预取不算。在异常路径上，若为 app_zt，仍会尽力写入空字符结尾。
    形参取有符号的 ptrdiff_t 而不是 size_t，理由见 read() 的同名说明—— 本函数同样写的是调用方的缓冲区，无符号形参下负的容量会变成 SIZE_MAX， 一路填到遇分隔符或 EOF 为止。

template<typename TChar>
template<typename TSelf>
TChar * IOv2::istream_operators< TChar >::read ( this TSelf & self,
TChar * s,
std::ptrdiff_t n )
inline

从流中读取恰好 n 个字符到 s。

这是非格式化提取。若在读满 n 个字符前到达 EOF，则视为失败。

模板参数
TSelf派生的具体流类型（由 deducing-this 推导）。
参数
s目标缓冲区。当 n != 0 时不得为空指针。
n要读取的字符数，必须非负。
返回
指向最后一个写入位置之后的指针（即 s + 实际读取数）。
异常
stream_error若 n 为负、s 为空指针而 n != 0，或无法读满 n 个字符。
注解
未能读满时置位 eofbit。
形参取有符号的 ptrdiff_t（与标准的 std::streamsize 一致）而不是 size_t：读取长度 常由含 size_t 的算式得出（end - cur、cap - used），越界时会回绕成巨值，有符号 形参可让传参时的窄化把回绕抵消回来、还原成负数并在此拒掉。无符号形参下 read(s, -1) 会一路读到输入耗尽，写入量与缓冲区大小完全无关。
