详细描述

template<typename CharT>
class IOv2::numeric< CharT >

基于 locale 的数值格式化与解析 facet。

封装了 numeric_conf<CharT> 提供的 locale 参数（小数点、千位分隔符、分组规则、布尔名称） 和 ctype<CharT> 提供的字符扩宽能力，通过 put() 系列重载将数值格式化为字符序列， 通过 get() 系列重载从字符流中解析数值。

模板参数
CharT字符类型。

构造函数，初始化所有 locale 相关参数并预先扩宽输入/输出原子字符集。

从 numeric_conf 中复制小数点、千位分隔符、分组规则和布尔名称， 然后通过 ctype::widen_seq 与 ctype::widen 将各原子字符扩宽为目标字符 类型，分别填充 m_in（用于解析）和 m_out（用于格式化）。 在 wchar_t 和 char32_t 类型下，还会在 debug/sanitizer 构建中断言 扩宽结果的单射性。

模板参数
TConfPtr满足 shared_ptr_to<numeric_conf<CharT>> 约束的共享指针类型。
TCtypePtr满足 shared_ptr_to<ctype<CharT>> 约束的共享指针类型。
参数
p_obj指向 numeric_conf 配置对象的共享指针，不得为空。
p_ctype指向 ctype 配置对象的共享指针，不得为空。
异常
io_error若任一指针为空。

从字符流中解析布尔值。

若 boolalpha 标志未设置，则将输入解析为 long（有效值为 0 或 1）， 超出范围则按 LWG 23 将结果设为 true 并失败。 若设置了 boolalpha，则将输入字符与 truename()/falsename() 逐字符前缀匹配， 以最长匹配确定结果；若无法确定，则按 LWG 23 将结果设为 false 并失败。 名字之前的流填充字符先被跳过，除非它就是某个名字的首字符。 解析失败时抛出异常。

模板参数
TIter输入迭代器类型。
TSent哨兵类型，满足 std::sentinel_for<TIter>。
参数
beg输入范围的起始迭代器。
end输入范围的结束哨兵。
io提供格式标志与填充字符的流对象。
v解析成功后写入结果的布尔值引用。
返回
消费输入后的迭代器。
异常
stream_error若解析失败。
