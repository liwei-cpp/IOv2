宏定义说明

◆ IOV2_HAS_CHRONO_TZDB

#define IOV2_HAS_CHRONO_TZDB   0

标准库的 <chrono> 有没有时区数据库（std::chrono::tzdb、time_zone、zoned_time、 locate_zone 等）：有为 1，没有为 0，总有定义，可直接用于 #if。

为 0 时，timeio 去掉以 time_zone 或 zoned_time 为参数的接口；Z 只认得 base_ft<timeio>::s_unknown_zone 与 UTC（sys_time 的 Z 写的就是它）；std::tm 的 Z 按"值供不出"退化为字面量，因为 tm_zone 里的缩写写出去读不回来。z 不受影响。

只能是宏：数据库缺席时 time_zone、zoned_time 这些类型本身不存在，写出它们的声明 在解析阶段就出错，requires 与 if constexpr 都去不掉，只能用 #if。

未定义时按标准库判断：libc++ 要求时区数据库已编入（_LIBCPP_HAS_TIME_ZONE_DATABASE）且 打开了实验库（-fexperimental-library），19 之前的版本没有完整的时区支持——Apple 的 libc++ （Xcode 26）关掉了它；libstdc++ 与 MSVC STL 看 __cpp_lib_chrono 是否达到 201907L。 也可以在包含 IOv2 之前自行定义为 0，强制当作没有。

◆ IOV2_NO_UNIQUE_ADDRESS

#define IOV2_NO_UNIQUE_ADDRESS   [[no_unique_address]]

[[no_unique_address]] 的可移植写法。MSVC ABI（cl.exe 与 clang-cl）为保持二进制兼容， 接受但忽略标准写法，只认 [[msvc::no_unique_address]]。
