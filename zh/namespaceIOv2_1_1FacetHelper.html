template<typename CharT>
CharT * IOv2::FacetHelper::add_grouping ( CharT * out,
std::basic_string_view< CharT > sep,
const std::vector< uint8_t > & grouping,
const CharT * first,
const CharT * last )
inline

在字符序列 [first, last) 中按 grouping 规则插入分组分隔符 sep，将结果写入 以 out 为起点的输出缓冲区，并返回写入结束位置的指针。

前置条件
  • grouping 非空（Debug 模式下通过 assert 验证）。
  • [first, last) 为合法区间，即 first <= last（Debug 模式下通过 assert 验证； 若 first > last，last - first 会被转换为一个巨大的无符号宽度，导致越界写入）。
  • out 指向的输出缓冲区容量足以容纳 (last - first) 个字符加上每个非前导分组对应 的一个分隔符（sep.size() 个字符）；缓冲区大小由调用方负责保证（不做运行时验证）。 (last - first) * (1 + sep.size()) 总是够用。
模板参数
CharT序列元素及分隔符的字符类型。
参数
out指向输出缓冲区起始位置的指针。
sep插入到各分组之间的分隔符，可以是多个字符（如 UTF-8 的 U+202F）。
grouping使用 adjust_grouping() 建立的内部 uint8_t 约定表示的分组规格： 1–255 为显式分组大小，0 为唯一停止哨兵，最后一个 1–255 元素对所有后续分组隐式重复。
first输入字符序列的起始指针。
last输入字符序列的末尾指针（独占上界）。
返回
指向写入输出缓冲区最后一个元素之后位置的指针。

◆ adjust_grouping()

void IOv2::FacetHelper::adjust_grouping ( std::vector< uint8_t > & grouping)
inline

将原始 POSIX 风格的分组向量原地规范化为内部约定格式；若向量不含可用约束则将其清空。

内部约定（uint8_t，平台无关）
  • 1–255：显式分组大小。
  • 0：停止标志——此点之后不再分组（**唯一**哨兵值）。
  • 若最后一个元素为 1–255，则对所有后续分组隐式重复；若最后一个元素为 0，则显式停止优先。
对原始 POSIX 输入所做的转换
  • **POSIX "0 = 重复前一分组"**：将 0 及其后的所有元素丢弃。POSIX 格式 [N1, ..., Nk, 0, ...] 在本约定中变为 [N1, ..., Nk]，因为最后一个元素的 隐式重复语义已完全覆盖该情形。
  • **POSIX CHAR_MAX（= 停止）**：改写为内部 0。CHAR_MAX 在有符号 char 平台上 为 127，在无符号 char 平台上为 255；经此步骤后调用方无需关心平台的 char 符号性。
注解
**顺序至关重要**：必须先去除 POSIX "0 = 重复" 标记，再执行 CHAR_MAX → 0 改写， 否则新引入的内部停止哨兵会被误认为 POSIX 重复标记而被丢弃。
参数
grouping待原地规范化的原始 POSIX 分组向量。

◆ is_c_locale_name()

bool IOv2::FacetHelper::is_c_locale_name ( const std::string & name)
inline

判断区域设置名称 name 是否指代 C/POSIX 区域设置。

POSIX 区域设置名称的形式为 language[_territory][.codeset][@modifier]。 "C.UTF-8"、"C.utf8"、"C.UTF-8@euro" 等拼写与 "C" 指代同一个区域设置， 但精确比较无法识别它们：codeset 段在查表前会被规范化（去除非字母数字字符后转为 小写），因此可接受的拼写不构成有限集合。本函数改为截取 . 与 @ 之前的语言段 再比较。语言段本身区分大小写（"c"、"posix" 均非合法名称），故不作大小写折叠。

光比较语言段还不够："C.BOGUS"、"C@euro"、"POSIX.utf8" 的语言段都是 C/POSIX， 而 newlocale() 并不接受它们。语言段匹配之后因此还要用 clocale_wrapper 探测一次， 名称无法实例化就抛。校验放在这里而不是留给调用方的常规路径，是为了不依赖"每条常规 路径都会自行构造 `clocale_wrapper`"这一隐含前提。"C" 与 "POSIX" 由标准保证存在， 直接短路，无须探测；语言段不匹配的名称（如 "en_US.BOGUS"）不归本函数认领，一律 返回 false 而不探测。

参数
name待检查的区域设置名称。
返回
若 name 的语言段为 "C" 或 "POSIX" 则返回 true，否则返回 false。
异常
io_error语言段为 "C" 或 "POSIX"，但 newlocale() 无法实例化该名称。

◆ punct_distinct()

template<typename CharT>
bool IOv2::FacetHelper::punct_distinct ( std::basic_string_view< CharT > sep,
std::basic_string_view< CharT > point )
inline

判断千位分隔符与小数点能否在输入里区分开：两者都非空，且谁也不是谁的前缀。

解析时逐字符同时比对两者，读到第一个不同的字符才判定是哪一个。若一个是另一个的前缀 （相等也算），较短的那个永远先匹配完，较长的那个就读不到了；此时只能关掉分组。

返回
能区分开则为 true。

◆ take_punct()

template<typename TIter, std::sentinel_for< TIter > TSent, typename CharT>
punct_kind IOv2::FacetHelper::take_punct ( TIter & beg,
TSent end,
std::basic_string_view< CharT > sep,
std::basic_string_view< CharT > point,
bool consume_point )
inline

在输入的当前位置识别千位分隔符或小数点，两者都可以由多个字符组成。

逐字符同时比对两者，读到第一个不同的字符才判定；调用方须保证两者能区分开（见 punct_distinct），不参与识别的那个传空串。试探读过的字符若最终不是标点，就用 step_back 退回，数字照常在此结束：例如千位分隔符为 U+202F（UTF-8 E2 80 AF）时， 100€（€ 为 E2 82 AC）读出 100，€ 留在输入里。迭代器无法退回时结果为 punct_kind::torn，已读的字符丢失。

参数
consume_point为 false 时，识别出的小数点不读过（多字符的小数点已读的部分 尽量退回）——整数解析在小数点前停下，把它留在输入里。

◆ verify_grouping()

bool IOv2::FacetHelper::verify_grouping ( const std::vector< uint8_t > & grouping,
const std::vector< uint8_t > & grouping_tmp )
inline

验证已解析的分组序列 grouping_tmp 是否符合 numpunct::grouping 所规定的 grouping 约束。

前置条件
grouping 和 grouping_tmp 均非空；仅在 Debug 模式下通过 assert 验证，Release 模式下由调用方保证。违反该前置条件将导致 size() - 1 下溢为 SIZE_MAX，后续索引 越界读取。调用方可保证非空性，因为 grouping_tmp 仅在 !grouping.empty() 分支内 填充，故 grouping_tmp 非空蕴含 grouping 非空。

grouping 使用由 adjust_grouping() 建立的内部 uint8_t 约定：1–255 为显式分组 大小，0 为唯一停止哨兵，最后一个 1–255 元素对所有后续分组隐式重复。

参数
grouping参考分组规格（来自 numpunct::grouping），使用内部 uint8_t 约定。
grouping_tmp解析过程中实际观测到的各分组大小序列。
返回
若 grouping_tmp 符合 grouping 的约束则返回 true；否则返回 false。
