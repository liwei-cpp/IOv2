详细描述

template<typename CharT>
class IOv2::collate_conf< CharT >

collate<CharT> facet 的底层实现类。

通过 C 标准库的 strcoll/strxfrm 和宽字符 wcscoll/wcsxfrm 实现基于 locale 的字符串比较与排序键变换。 所有输入均为以空字符结尾的字符串；按内嵌空字符分段由 collate facet 负责。

注解
此类不是线程安全的，多线程并发由更高层次的代码处理。
模板参数
CharT字符类型，支持 char、wchar_t、char8_t 和 char32_t（仅限 UTF-32 平台）。

template<typename CharT>
IOv2::collate_conf< CharT >::collate_conf ( const std::string & name)
inline

构造函数，初始化 collate_conf 并绑定到指定的 locale。

当 CharT 为 char8_t 时，额外验证 m_inter_locale 的 LC_CTYPE 编码集是否为 UTF-8。 collate<char8_t> 内部经由窄字符 strcoll/strxfrm 路径处理， 这两个函数只有在 LC_CTYPE 编码集为 UTF-8 时才能正确解析 UTF-8 字节输入。 验证方法是用已知码点对 locale 自身的多字节解码器（mbrtoc32）进行探测—— mbrtoc32 与 strcoll/strxfrm 使用相同的 LC_CTYPE 编码集， 且由于 m_inter_locale 以 LC_ALL_MASK 从单一名称构造，其 CTYPE 与 COLLATE 编码集一致，故探测结果可代表两者的实际编码。

参数
namelocale 名称字符串（例如 "zh_CN.UTF-8"）。
异常
io_error若 C 库无法实例化 name，或 CharT 为 char8_t 且 inter locale 的编码集不是 UTF-8。

比较两个以空字符结尾的字符串的排列顺序。

在 inter locale 下调用 strcoll/wcscoll。不处理内嵌的空字符： 按空字符分段由 collate facet 负责。

结果为 std::weak_ordering：strcoll 返回 0 只表示两串等价， 内容不同的串也可能等价（例如某些在所有层级上都被忽略的字符）。

参数
s1第一个字符串，以空字符结尾。
s2第二个字符串，以空字符结尾。
返回
表示两串排列关系的 std::weak_ordering 值。

◆ transform()

template<typename CharT>
virtual std::size_t IOv2::collate_conf< CharT >::transform ( const CharT * src,
CharT * dest,
std::size_t n ) const
inlinevirtual

将以空字符结尾的字符串变换为不透明的排序键。

在 inter locale 下调用 strxfrm/wcsxfrm，将排序键及结尾空字符写入 dest。 输出是保序的排序权重——对结果执行 strcmp/wcscmp 等价于对原串执行 strcoll/wcscoll——并非可读的字符序列，也不应被解码。

参数
src待变换的字符串，以空字符结尾。
dest写入排序键的目标缓冲区。
ndest 的容量（字符数），须大于 transform_length(src)。
返回
排序键的字符数，不含结尾空字符。
异常
io_error若 strxfrm/wcsxfrm 报告失败，或 n 不足以容纳排序键及结尾空字符。

计算以空字符结尾的字符串的排序键长度。

在 inter locale 下调用 strxfrm/wcsxfrm（目标缓冲区为空、容量为 0）。 返回值不含结尾空字符；调用 transform() 时目标容量须至少为返回值加 1。
