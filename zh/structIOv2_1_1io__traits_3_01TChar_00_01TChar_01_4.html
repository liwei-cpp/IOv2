template<typename TChar>
struct IOv2::io_traits< TChar, TChar >

流自身字符类型的单个字符的读写：os << c / is >> c。

对应标准的 operator<<(basic_ostream<charT>&, charT) 与 operator>>(basic_istream<charT>&, charT&)。两个方向都不需要 locale：写出不加宽，读入 也不判空白——前导空白已由 sentry 按 skipws 跳过，之后的第一个字符无论是什么都被取走。

模板参数
TChar流的字符类型。

写出一个字符，按需补齐到字段宽度。

注解
字符已经是流的字符类型，直接写出，不加宽，也不查 locale。
width() 为 0 时直接写一个字符，不经 ostream_insert，也就没有什么可消费； 非 0 时经 ostream_insert 补齐，width() 由它消费。
参数
iter输出迭代器。
io提供 width() / fill() / adjustfield 的流。
c要写出的字符。
返回
写完之后的输出迭代器。
异常
stream_error若所需填充量超过 ios_defs::max_pad_count。
