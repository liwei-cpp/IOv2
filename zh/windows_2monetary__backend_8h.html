详细描述

monetary facet 的 Windows（UCRT）后端：在 clocale_user 切换后的线程 locale 下读 localeconv()。

  • UCRT 的 lconv 没有 C99 的国际格式标志（int_p_cs_precedes 等），这里以国内格式的标志 顶替，与 libc++ 在 Windows 上的做法相同；国际格式的小数位数仍取 int_frac_digits。 于是 en-US 的国际格式是 USD1,234.56。
  • 标志用 UCRT 由 NLS 的 ICURRENCY/INEGCURR 换算出的值，与 MSVC STL、libc++ 相同。 这一换算有损：INEGCURR 12（$ -1.1）与 13（1.1- $）按 C 的定义是 sep_by_space 为 2，UCRT 给的是 1，故 nl-NL 的负数写作 €- 1.234,56；Windows 上 sep_by_space 从不为 2。
  • int_curr_symbol 取自 NLS 的 LOCALE_SINTLSYMBOL，只有三个字母（"USD"），没有 C 规定的 第四个字符。
  • 字符串另有 _W_ 宽字符形式，宽字符配置直接用它们；窄字段按 locale 的代码页编码，代码页 装不下的字符已被近似（French_France.1252 的窄千位分隔符是 0xA0）。
