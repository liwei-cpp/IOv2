概念定义

template<typename T>
concept IOv2::unordered_key = std::equality_comparable<T>
&& requires (const T& v) {
{ std::hash<T>{}(v) } -> std::convertible_to<std::size_t>;
}
IOv2::unordered_key
定义 metafunctions.h:349

详细描述

判断类型 T 能否作为无序容器（std::unordered_map 等）在默认哈希器与判等器下的键。

要求 T 可判等，且 std::hash<T> 可默认构造、以 const T& 调用的结果可转换为 std::size_t。没有特化的 std::hash<T> 是被禁用的特化，不满足本概念。

不要求可拷贝：只能移动的类型同样可以作为无序容器的键。需要拷贝键的使用者应另行约束。
