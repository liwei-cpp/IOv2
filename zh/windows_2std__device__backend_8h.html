详细描述

std_device 的 Windows 后端：基于 CRT 的 _read()。

注解
fd 0 保持 CRT 的默认文本模式（CRLF 读作 LF），本后端不调用 _setmode：那会改变 进程全局状态，影响用户自己的 stdio。代价是：文本模式下 _read 遇到字节 0x1A（Ctrl+Z） 即视为 EOF，不只控制台，管道与重定向的文件也一样，所以经 stdin 传入的二进制数据会在第一个 0x1A 处被截断。
没有 O_NONBLOCK 与 EINTR，读不需要重试。
