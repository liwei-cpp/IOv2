详细描述

messages_conf 的 char8_t 特化，以 UTF-8 字符串为键的翻译 facet。

从 .mo 文件加载翻译字典，直接使用 char8_t 字符串作为键和值， 无需任何编码转换。

构造函数，加载指定域和语言的翻译字典。

参数

异常
io_error如果 throw_if_fail 为 true 且字典加载失败。

◆ translate()

virtual const std::u8string * IOv2::messages_conf< char8_t >::translate ( const std::u8string & ori) const
inlinevirtual

查找 ori 的翻译。

返回指向字典中翻译的指针，而非翻译字符串本身，以避免与调用者参数产生别名 关系（不会悬空，也不会产生额外拷贝）。messages facet 在此之上处理 gettext 的"未命中时返回原文"语义（按值类别安全地进行）。nullptr 明确表示"未找到"， 与找到了但翻译恰好为空的情况不同。

参数
ori原始字符串（msgid）。
返回
指向字典中翻译字符串的指针，若未找到则为 nullptr。
