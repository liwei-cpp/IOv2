详细描述

POSIX locale_t 对象的 RAII 包装类。

注解
此类需要 POSIX locale 扩展（在 Linux、macOS 上可用）。 在 Windows 上不可用。
此类不是线程安全的。

IOv2::clocale_wrapper::clocale_wrapper ( const std::string & name)
inlineexplicit

以 newlocale(LC_ALL_MASK, name) 构造。

name 按 std::string 的全长解释：含内嵌 NUL 的名字在此拒绝，而不是在 c_str() 处 静默截断——否则首字节为 NUL 的名字会变成 ""、按环境解析，调用方显式给的名字被丢掉 却没有任何报告。这是唯一一处本类自己做的判定；名字是否合法仍由 C 库说了算。

参数
namelocale 名；"" 按 POSIX 规则查环境。
异常
io_errorname 含内嵌 NUL，或 newlocale 拒绝该名字。

◆ name()

std::string IOv2::clocale_wrapper::name ( ) const
inlinenodiscard

返回本 locale 的 LC_CTYPE 名字。

这是 locale 自己报出的**已解析**名字，不是构造时的实参：以 "" 构造时，返回的是当时 查环境得到的具体名字（如 "C.UTF-8"）；别名按平台规范化（glibc 把 "POSIX" 报成 "C"）。返回值可再交给 newlocale 得到同一个 LC_CTYPE。

注解
实现依赖 glibc 扩展 nl_langinfo_l(_NL_LOCALE_NAME(LC_CTYPE), …)（<langinfo.h>）； POSIX 没有等价接口，musl 等 libc 需要另想办法（例如自己保存解析后的名字）。
返回
已解析的 locale 名字。
异常
io_error若本对象处于 moved-from 状态。
