详细描述

messages facet 的 Windows 后端。

Windows 没有存放 .mo 的约定目录。GNU gettext 在那里按自身的安装位置定 LOCALEDIR， 而一个没有安装前缀的库做不到，故不设缺省：未绑定目录的文本域没有翻译。

用户的语言偏好存在系统设置里，不经过环境变量：GetUserPreferredUILanguages 以 MUI_LANGUAGE_NAME 给出用户界面语言列表（如 zh-CN、en-US），GNU libintl 也从这里取。
