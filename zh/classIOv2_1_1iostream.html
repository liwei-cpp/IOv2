requires (dev_cpt::support_get<TDevice> && dev_cpt::support_put<TDevice>)
class IOv2::iostream< TDevice, TChar >

双向字符流：把一条 iochannel 与一个 locale 组合成带格式化的输入输出接口。

◆ in_sentry_type

template<io_device TDevice, typename TChar >
using IOv2::iostream< TDevice, TChar >::in_sentry_type = in_sentry<iostream<TDevice, TChar>, true>

本流的输入哨兵类型。哨兵在每次格式化输入前检查流状态、按需刷新 tie 目标并按 skipws 跳过前导空白。模板实参 true 表示本流是双向的，哨兵因此会先 switch_to_get()；那一步 可能被转换器拒绝，见 switch_to_put() 上的说明。

◆ out_sentry_type

template<io_device TDevice, typename TChar >
using IOv2::iostream< TDevice, TChar >::out_sentry_type = out_sentry<iostream<TDevice, TChar>, true>

本流的输出哨兵类型。哨兵在每次格式化输出前检查流状态、按需刷新 tie 目标、（追加模式下） 定位到末尾，并在析构时按构造实参 is_unit_buf 决定是否自动刷新。模板实参 true 表示 本流是双向的，哨兵因此会先 switch_to_put()，那一步可能被转换器拒绝；第三个实参取默认 的 false，即本流不是标准流。
