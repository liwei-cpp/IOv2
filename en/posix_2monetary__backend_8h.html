Detailed Description

POSIX backend of the monetary facet: localeconv(), read under the thread locale a clocale_user switched to. glibc has no localeconv_l, so the _l form is not used.

POSIX's lconv carries C99's international format flags (int_p_cs_precedes and the rest), which are read as they are. macOS sets them to the national ones (in every locale the probe looked at), so the international format there is laid out like the national one: en_US's has no space, USD1,234.56, where glibc's is USD 1,234.56.
