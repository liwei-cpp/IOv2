Detailed Description

Defines the timeio facet, which provides locale-aware formatting (put) and parsing (get) of date/time values using strftime/strptime-style format specifiers, including E/O modifiers and era extensions.

Also defines the following helper types:

  • date_parse_helper, time_parse_helper, time_zone_parse_helper: conditionally activated parse-state containers that serve as base classes of time_parse_context;
  • time_parse_context: an aggregate parse context used as the output argument of get(), providing conversion operators to std::chrono::year_month_day, std::chrono::hh_mm_ss, and std::chrono::zoned_time.
