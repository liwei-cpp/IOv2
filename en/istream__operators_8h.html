Detailed Description

Defines the formatted and unformatted extraction facilities for input streams. Includes the input sentry in_sentry, the input-stream concept istream_type, the istream_operators mix-in base that carries the various extraction operations (get/peek/read/ignore/putback), and the extraction operator>>: one generic (dispatching the type to the io_traits<TChar, TValue> extension point) plus one for function-pointer ios_base manipulators.
