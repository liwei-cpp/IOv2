copyable_atomic< bool > m_sync_with_stdio
 When true this stream reads stdin byte by byte, when false through its own buffer; that semantics is baked into the kernel type when the iochannel is built, so nothing but this flag's own reads and writes consults it. Writes happen under io_mutex(); the atomic is only so that synced_with_stdio() reads lock-free like the library's other query functions.
