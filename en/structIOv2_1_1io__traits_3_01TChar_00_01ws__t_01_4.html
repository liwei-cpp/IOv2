Detailed Description

template<typename TChar>
struct IOv2::io_traits< TChar, ws_t >

Extension-point specialization for ws: provides only the iterator form of sread, which skips the whitespace characters that follow.

The iterator form rather than the stream form is what makes it composable: another type's iterator-form sread can call compose_read(it, end, io, loc, ws) between two components to skip whitespace – a component's own sread does not skip leading whitespace (that is the sentry's job), and there is no sentry inside a composition. The lock, the sentry and the catch all belong to the operator.

Reaching the end does not throw; end is simply returned. In a composition the next component decides whether that is an error; for is >> ws the operator exempts ws_t from the end-of-input precheck after the sentry, the iterator reports saw_eof, and the operator sets eofbit alone, no failure bit, matching std::ws. A stream that already carries eofbit on entry is rejected by the sentry (strfailbit), so while (is >> ws) always terminates.

Note
The skipping has nothing to do with the stream's skipws flag (or noskipws): this member skips unconditionally, so is >> noskipws >> ws still skips whitespace — which is exactly what ws is supposed to do. With skipws set the sentry skips first and this member then meets a non-whitespace character or the end straight away; the result is the same.

A manipulator's direction is expressed by which member exists: only sread is here, so os << ws leaves the insertion operator unsatisfied and there is no viable overload. A constraint would not be enough – iostream satisfies both stream concepts, so if both members existed both directions would call successfully.
