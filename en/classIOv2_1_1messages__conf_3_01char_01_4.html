Detailed Description

Specialization of messages_conf for char, with encoding conversion via a wchar_t converter.

Loads the UTF-8 translation dictionary from a .mo file, then converts strings to the current char encoding using the specified char↔wchar_t converter facet. Only supported on platforms where wchar_t is UTF-32.

Constructor that loads the translation dictionary with encoding conversion.

Unlike other specializations, this one requires an extra cvt_ft parameter naming the char↔wchar_t converter facet. This is the public, stable construction API, so the arguments cannot be bundled into a struct without breaking callers or diverging from the sibling specializations' (domain, lang) argument shape.

Parameters
domainThe text domain name.
langThe candidate language string, or empty (use environment variables).
cvt_ftThe name of the char↔wchar_t converter facet.
throw_if_failIf true (default), throws on failure; otherwise silently leaves the dictionary empty.
Exceptions
io_errorIf throw_if_fail is true and dictionary loading fails.
