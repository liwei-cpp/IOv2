Detailed Description

Declarations of the few Win32 functions the Windows backends use, in place of <windows.h>.

<windows.h> has an include guard, so whatever macros we included it under (WIN32_LEAN_AND_MEAN, NOMINMAX) would bind every later include in the user's code. The signatures here match <windows.h> exactly, so the two coexist.
