Detailed Description

Windows (UCRT) backend of the numeric facet: localeconv(), read under the thread locale a clocale_user switched to.

The UCRT's lconv has, besides the narrow fields, _W_decimal_point and _W_thousands_sep, taken from NLS's LOCALE_SDECIMAL/LOCALE_STHOUSAND, and the wide configurations use them as they are. The narrow fields are in the locale's code page, which approximates what it cannot hold: on real Windows the narrow thousands separator of French_France.1252 is "\xA0", the wide one U+202F.

Windows has no source of boolean names: NLS has no such item, nor does the data of the system's icu.dll (the probe checked ICU 64 on Windows Server 2022 and ICU 72 on 2025), so they are always empty and the configuration classes fall back to "true"/"false", as the MSVC STL does.
