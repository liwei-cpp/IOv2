Detailed Description

Windows (UCRT) backend of clocale_wrapper.

A UCRT _locale_t can neither be copied nor report its name, and there is no uselocale. So this backend resolves the name when the locale is created and keeps it: a copy is another _create_locale from the kept name, and switching the thread's locale puts the thread in _ENABLE_PER_THREAD_LOCALE mode and calls setlocale, which in that mode changes this thread alone, leaving the global locale and other threads untouched. Resolving the name happens in the same mode and is undone at once.

Resolving also keeps the BCP-47 names of LC_CTYPE and LC_COLLATE (en-US, say, from ___lc_locale_name_func), for facet backends calling LCMapStringEx, CompareStringEx and the other NLS functions that take a locale by name; the "C" locale has no such name. It keeps the code page of LC_COLLATE (___lc_collate_cp_func) as well, which the collate backend converts narrow strings to UTF-16 with.
