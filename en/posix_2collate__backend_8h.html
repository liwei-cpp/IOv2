Detailed Description

POSIX backend of the collate facet: the POSIX.1-2008 strcoll_l, wcscoll_l, strxfrm_l and wcsxfrm_l, which leave the thread's locale alone. macOS declares them and nl_langinfo_l in <xlocale/_*.h>, included here explicitly.

POSIX reserves no return value of these functions for failure; it only lets them set errno. glibc never reports a failure; macOS sets EILSEQ on a byte sequence invalid in the encoding, yet returns an ordinary value. So this backend clears errno before a call, checks it after, and puts the caller's errno back, as libstdc++'s collate::do_transform does.
