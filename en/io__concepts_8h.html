Detailed Description

Concept and type-utility file for the I/O layer.

  • ext_to_int, which derives the internal character type ultimately exposed by a converter pipeline from a "root converter + converter creator" pair; it mainly serves the CTAD of the iochannel family.
  • cvt_direction_capable / cvt_fits_direction, which decide whether a converter pipeline is capable enough for a channel of a given direction.
