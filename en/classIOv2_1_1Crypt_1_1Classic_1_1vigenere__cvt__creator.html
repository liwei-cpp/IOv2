Detailed Description

template<typename TChar>
class IOv2::Crypt::Classic::vigenere_cvt_creator< TChar >

Factory class for vigenere_cvt, for uniform construction of Vigenère cipher converter instances within a pipeline.

Validates and stores the key at construction time; subsequent create() calls reuse the same key.
