Detailed Description

template<template< typename > class TFacet>
class IOv2::base_ft< TFacet >

Intermediate base class parameterized on the facet template.

Acts as a bridge layer between abs_ft and a concrete ft_basic specialization, establishing an inheritance hierarchy keyed on the facet template. This allows different character-type specializations of the same facet template to share a common intermediate base.

TFacetThe facet template, e.g. ctype, collate, etc.
