Detailed Description

Defines the common operations shared by input and output streams. Includes the process-wide lock tie_graph_mutex() that guards the entire tie graph, and the stream_common_operators mix-in base carrying positioning (tell/seek/rseek), underlying device management (device/detach/attach), conversion-behavior adjustment (adjust/retrieve), locale access, and stream tying (tie).
