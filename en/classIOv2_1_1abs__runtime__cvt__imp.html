Detailed Description

template<io_device TDevice, typename TInt>
class IOv2::abs_runtime_cvt_imp< TDevice, TInt >

Abstract base class for the type-erased converter implementation. Declares the complete virtual interface required by a converter, allowing runtime_cvt to operate on any concrete converter through a base-class pointer. Copy assignment and move are disabled to prevent slicing; polymorphic copying is performed via clone().
