Detailed Description

ChaCha20 stream-cipher converter.

This file provides two components:

  • chacha20_cvt: A stream encryption/decryption converter backed by Botan's ChaCha20 implementation. In write (encryption) mode the IV is randomly generated and prepended to the ciphertext stream; in read (decryption) mode the IV is read from the stream head.
  • chacha20_cvt_creator: A factory class for constructing chacha20_cvt instances uniformly within a pipeline.
