Detailed Description

template<typename CharT>

class IOv2::messages_conf< CharT >

Specialization of messages_conf for char32_t and a Unicode wchar_t.

Specialization of messages_conf whose encoding depends on a locale: char, and wchar_t on macOS.

Loads the UTF-8 translation dictionary from a .mo file and converts all strings to CharT: code point by code point for char32_t and a UTF-32 wchar_t (Linux), a character outside the BMP becoming a surrogate pair for a UTF-16 wchar_t (Windows). The encoding has nothing to do with a locale, so none is named at construction. macOS's wchar_t is not Unicode, and the specialization taking a locale name handles it (see detail::messages_locale_encoded).

Template Parameters
CharTThe character type: char32_t, or a UTF-32 / UTF-16 wchar_t.

Loads the UTF-8 translation dictionary from a .mo file, then converts it to the encoding of the locale named cvt_ft at construction:

  • A UTF-8 locale: char takes the .mo bytes as they are, unchecked, as messages_conf<char8_t> does; macOS's wchar_t has the locale's C library decode them.
  • Any other: char goes to a Unicode wchar_t first and on to the locale's encoding (Linux, Windows). macOS's wchar_t is not Unicode, so there is no reliable conversion, and both char and wchar_t throw io_error.

Only on macOS does wchar_t take cvt_ft. Portable code going through locale::involve_msg with the default arguments reads the same on all three platforms; giving throw_if_fail by position, as in involve_msg("app", "zh_CN", true), fails to compile for wchar_t on macOS, where the third parameter is the locale name.

Template Parameters
CharTchar, or wchar_t on macOS (see detail::messages_locale_encoded).

Constructor that loads the translation dictionary with encoding conversion.

Unlike other specializations, this one requires an extra cvt_ft parameter: the name of the locale whose encoding the strings are in. This is the public, stable construction API, so the arguments cannot be bundled into a struct without breaking callers or diverging from the sibling specializations' (domain, lang) argument shape.

Parameters
domainThe text domain name.
langThe candidate language string, or empty (use the environment, then the system's language preference; see filter_lang).
cvt_ftThe name of the locale whose encoding the strings are in (e.g. zh_CN.UTF-8).
throw_if_failIf true (default), throws on failure; otherwise silently leaves the dictionary empty. Only a bool is taken: a string literal is not turned into one, but picks the overload with dirname as the directory.
Exceptions
io_errorIf throw_if_fail is true and dictionary loading fails.
