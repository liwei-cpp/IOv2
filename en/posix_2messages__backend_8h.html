Detailed Description

POSIX backend of the messages facet.

A text domain bound to no directory is looked up in a default one. On a glibc system that is /usr/share/locale, where distributions keep their .mo files and GNU gettext's LOCALEDIR when it is installed under /usr. macOS has no such agreed place (third-party translations live under their own prefixes, Homebrew's say), so there is no default: an unbound domain has no translations.

The system's language preference: Linux has no source besides the environment (POSIX's locale is LC_ALL, LC_* and LANG, and "C" when none is set), so the list is empty. macOS keeps the user's language preference in the system settings, and a program started from the Finder has no LANG; it is read here with CoreFoundation's CFLocaleCopyPreferredLanguages, as GNU libintl does. macOS therefore has to link -framework CoreFoundation: the CMake target IOv2::iov2 and the pkg-config files carry it, and a user of the headers alone adds it themselves.
