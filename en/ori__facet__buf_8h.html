Detailed Description

Defines the ori_facet_buf singleton – a process-wide cache / interning pool for base facets and messages facets – and resolves the initial per-LC_* locale names from the environment at program startup. Also defines the messages-cache key type detail::msg_key and its std::hash specialization.
