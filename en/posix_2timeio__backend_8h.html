Detailed Description

POSIX backend of the timeio facet: nl_langinfo, read under the thread locale a clocale_user switched to.

Weekday and month names, AM/PM and the formats such as D_T_FMT exist on every POSIX system. Eras and alternative digits have data on glibc alone: glibc keeps its era table in a binary layout of its own (read through _NL_TIME_ERA_*) and its alternative digits as a run of NUL-separated strings, while macOS's nl_langinfo returns an empty string for ERA, ALT_DIGITS and the era formats such as ERA_D_FMT (Apple's Libc source marks them as not implemented), so the two functions here return nothing there. The ;-separated form POSIX specifies has no platform to test it on, and is not parsed.

What comes back is the C library's data as it is: how an empty era format falls back, what stands in for an empty T_FMT_AMPM, how the formats are normalized and how an era's direction is normalized are the configuration class's decisions.
