Detailed Description

Windows backend of file_device, opening files by their UTF-16 path.

  • Plain modes use _wfsopen(..., _SH_DENYNO): like fopen it leaves the file open to other processes, and unlike fopen / fopen_s MSVC does not mark it deprecated (fopen_s also denies sharing by default).
  • The UCRT's mode parser does not know x (it raises an invalid parameter, which ends the process by default), so modes with x go through _wsopen_s(_O_CREAT | _O_EXCL) and _fdopen instead: CreateFileW(CREATE_NEW) creates the file only if it does not exist, atomically, failing with errno == EEXIST, as POSIX O_EXCL does.
  • file_device always passes a mode with b; without one this would follow fopen into text mode, but that is never used.
