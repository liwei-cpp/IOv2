Detailed Description

Whether the pipeline that TCreator builds on top of root converter TRootCvt is capable enough for a channel whose direction is (IsIn, IsOut).

That is, cvt_direction_capable applied to the return type of TCreator::create(TRootCvt).

Note
This is the predicate used by base_channel's two creator-taking constructors. When it is not satisfied that constructor is removed, and with it the corresponding constructors of istream / ostream / iostream.
