Detailed Description

template<typename TChannel>
struct IOv2::ichannel_iterator< TChannel >::proxy

Return proxy for operator->, holding a copy of the character value.

Since a single-pass input iterator cannot return a pointer to a persistent object, the dereference result is carried by a proxy object.
