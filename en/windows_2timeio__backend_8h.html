Detailed Description

Windows backend of the timeio facet: the date and time data, read through NLS (GetLocaleInfoEx) by LC_TIME's BCP-47 name, from the same source as the UCRT's own.

  • Names: the weekdays (NLS counts from Monday; here from Sunday), the months (nominative, without LOCALE_RETURN_GENITIVE_NAMES, as the UCRT's B; no thirteenth month) and AM/PM (empty in 87 locales, which the configuration handles as it always has).
  • Formats: x from LOCALE_SSHORTDATE, X from LOCALE_STIMEFORMAT, and c the two joined by a space, as the UCRT's strftime has them. r takes the time format only where it is a 12-hour one, and is left empty otherwise for the configuration to supply "%I:%M:%S %p" (C makes r a 12-hour time; the UCRT's r copies the time format, which for de-DE is 24-hour). The era formats are left empty, that is, the plain ones. NLS's picture formats are translated into strftime specifiers; see timeio_from_picture.
  • The wide form goes into timeio_raw_data::wide for the wide configurations to take as it is; the narrow strings are converted by LC_TIME's code page, which is what the UCRT's narrow data is.
  • Eras and alternative digits: not this time (Windows has eras only in optional calendars), so both functions return nothing. Gregorian only: a locale whose default calendar is not (th-TH and others) is still written in the Gregorian calendar, unlike the UCRT's x.
