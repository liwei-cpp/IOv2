Detailed Description

Configuration class for the numeric<char> facet.

Extracts narrow-character (char) numeric formatting parameters from the specified locale, including the decimal point character, thousands separator, digit grouping rules, and boolean text names.

◆ numeric_conf()

IOv2::numeric_conf< char >::numeric_conf ( const std::string & name)
inline

Constructor that reads and initializes all numeric formatting parameters from the specified locale.

For "C" and "POSIX" locales, standard ASCII values are assigned directly. For other locales, all locale-dependent pointers (lconv*, nl_langinfo()) are snapshotted into raw strings while the locale guard is active, preventing invalidation by subsequent setlocale()/uselocale() calls; character conversion is then performed after the guard ends.

Parameters
nameThe locale name string (e.g., "zh_CN.UTF-8").
