Detailed Description

Whether converter TCvt is capable enough for a channel whose direction is (IsIn, IsOut).

Three cases, one per base_channel instantiation:

Direction Instantiation Requirement
IsIn && IsOut iochannel support_io_switch (which already implies support_get and support_put)
IsIn only ichannel support_get
IsOut only ochannel support_put
Warning
This must be applied to a concrete converter type, never to runtime_cvt. runtime_cvt implements every interface and throws cvt_error at run time when the capability is missing, so this predicate is vacuously true on it. Use cvt_fits_direction instead: it applies to the return type of TCreator::create(), which is where the capability information survives.
