Detailed Description

A stream's object lock: its own by default, or, given at construction, an external one, so that several streams share it.

The caller provides the external lock and keeps it alive at least as long as this object. Copy and move construction always give the new object its own lock, and assignment leaves each side with the lock it had – two independent streams should not share a lock without the user knowing, which matches copyable_mutex making fresh locks and never handing one over. Getting the lock is one indirection, with no branch.
