Detailed Description

Whether type T can serve as the key of an unordered container (such as std::unordered_map) under the default hasher and key-equality predicate.

Requires T to be equality comparable, and std::hash<T> to be default-constructible with its call on a const T& yielding something convertible to std::size_t. A std::hash<T> that has not been specialized is a disabled specialization and does not satisfy this concept.

Copyability is not required: a move-only type can be an unordered container's key as well. Users that copy keys must constrain that separately.
