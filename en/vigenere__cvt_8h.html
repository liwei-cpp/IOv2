Detailed Description

Vigenère cipher converter, for educational and demonstration purposes only.

Warning
NOT FOR PRODUCTION SECURITY USE.

This file provides two components:

  • vigenere_cvt: A bidirectional stream converter based on the Vigenère polyalphabetic substitution cipher, supporting both read (decryption) and write (encryption) directions as well as optional positioning.
  • vigenere_cvt_creator: A factory class for constructing vigenere_cvt instances within a pipeline.
