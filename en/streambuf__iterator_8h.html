Detailed Description

Defines the iterator adapters over stream buffers (streambuf):

  • istreambuf_iterator: a single-pass input iterator that reads a stream buffer character by character.
  • ostreambuf_iterator: an output iterator that writes a stream buffer character by character.

They correspond to the standard std::istreambuf_iterator / std::ostreambuf_iterator, letting algorithms and ranges operate directly on this library's stream buffers.
